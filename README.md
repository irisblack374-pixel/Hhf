## 🚀 Run

```bash
git clone https://github.com/irisblack374-pixel/Hhf.git
cd Hhf
pip install -r requirements.txt
python bot.py
```

Create `.env`:

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
PREFIX=!
```

> Never upload your real `.env` or bot token.

# Hhf

بوت Discord لإدارة متجر خدمات TikTok، مبني باستخدام Python و discord.py.

## ✨ المميزات

- 🛒 عرض خدمات المتجر والكميات المتاحة.
- 🎫 إنشاء تذاكر تلقائية للطلبات.
- 💾 حفظ التذاكر المفتوحة في `tickets.json`.
- 🔒 إغلاق التذاكر مع التحقق من صلاحيات الدعم.
- ⭐ نظام تقييم من 1 إلى 5.
- 📢 إرسال إعلانات من الإدارة.
- 📝 Logs لفتح وإغلاق التذاكر.
- ⏳ حماية من إنشاء طلبات متكررة بسرعة.
- ⚙️ إعدادات السيرفر من متغيرات البيئة.
- 🔐 التوكن لا يوضع داخل الكود.

## 📁 الملفات

```
Hhf/
```

## 🛠️ المتطلبات

- Python 3.11 أو أحدث.
- Bot Token من Discord Developer Portal.
- تفعيل **Message Content Intent** و **Server Members Intent** عند الحاجة.
- صلاحيات مناسبة للبوت لإنشاء وإدارة قنوات التذاكر.

## ⚙️ إعداد متغيرات البيئة

لا تضع التوكن داخل GitHub أو داخل ملفات المشروع.

أضف متغير البيئة التالي في الاستضافة:

```env
DISCORD_TOKEN=ضع_توكن_البوت_هنا
```

ولنظام التذاكر يمكنك إضافة:

```env
ORDERS_CHANNEL_ID=1376258517303951432
SUPPORT_ROLE_ID=0
TICKET_CATEGORY_ID=0
LOG_CHANNEL_ID=0
```

### شرح الإعدادات

| المتغير | الاستخدام |
|---|---|
| `DISCORD_TOKEN` | توكن البوت |
| `ORDERS_CHANNEL_ID` | روم استقبال الطلبات |
| `SUPPORT_ROLE_ID` | رتبة الدعم التي يمكنها إدارة التذاكر |
| `TICKET_CATEGORY_ID` | الكاتيجوري الذي تُنشأ داخله التذاكر |
| `LOG_CHANNEL_ID` | روم تسجيل عمليات التذاكر |

إذا تركت `SUPPORT_ROLE_ID` أو `TICKET_CATEGORY_ID` أو `LOG_CHANNEL_ID` بقيمة `0`، فلن يتم استخدام هذا الخيار.
